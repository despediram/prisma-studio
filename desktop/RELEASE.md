# Prisma Studio 0.1.7

Corrige o painel de ajustes no celular para manter a foto maior e acessível. A troca de ferramentas abre os controles corretos, e a seleção ativa pode ser removida pelo painel.

Luz local processa somente os blocos tocados pelo pincel, reduzindo a memória usada em imagens grandes. Adiciona remoção de objetos offline por exemplos de textura, com prévia, comparação, cancelar e desfazer/refazer. Cenas complexas precisam de conferência visual.

Cálculos e padrões dos pôsteres preservados. Windows e Android usam o mesmo editor e recursos locais.
